# dejaview-frontend

Веб-интерфейс DejaView: одностраничное приложение для мультимодального поиска фильмов и личного кинотрекера.

## Зона ответственности

- Четыре режима поиска в одном окне: текст, изображение, видео, аудио (загрузка и запись)
- Страница фильма: постер, рейтинг, актёры, сюжет, отзывы
- Профиль: списки «Хочу посмотреть» и «Просмотрено», история, статистика
- Адаптивная вёрстка (десктоп и мобильные)

## Стек

React / Vue · TypeScript

## Ссылки

## Как работаем

- Ветка от `main`: `feat/...`, `fix/...` (нейминг — в соглашениях)
- Изменения только через Pull Request с ревью; прямой push в `main` закрыт

Структура проекта появится вместе с командой.
