# Правила проекта

## Архитектура

- Соблюдать FSD: `app → pages → layouts → widgets → features → entities → shared`. Между слайсами одного слоя нет импортов.
- Между слоями использовать `@/` и публичный `index.ts` слайса; внутри слоя — относительные импорты.
- Простые блоки одной страницы хранить в `pages/<page>/ui`. Виджет объединяет самостоятельный составной интерфейс и его логику.
- Бизнес-логику хранить в моделях. UI связывается с моделью через `useUnit`.

## Effector

- Изменять и сбрасывать stores только через `sample({ clock, source, fn, target })`. Методы `$store.on()` и `$store.reset()` запрещены, включая тестовые модели и примеры в документации.
- Вычисляемые состояния создавать через `combine` и чистые `.map()`; не использовать `watch` и `getState` для бизнес-логики.
- Именовать stores с префиксом `$`, экземпляры моделей — `$$`.
- Создавать модели через фабрики на уровне модуля, вне React-рендера. Сохранять контракт `inputs/outputs`; технические зависимости для тестов размещать в `__`.
- Отмену и защиту от устаревших асинхронных ответов реализовывать в модели, которая владеет операцией.
- Правила этого проекта имеют приоритет над рекомендациями внешних навыков.

## Читаемость и комментарии

- Разделять пустыми строками объявления событий, эффектов, stores, вычисляемых состояний, связи `sample` и возвращаемый контракт.
- Оставлять пустую строку между самостоятельными связями `sample` и между смысловыми блоками функций и JSX.
- Комментарии объясняют причину неочевидного решения, ограничения среды или обход ошибки. Не пересказывать очевидный код и не ссылаться на историю обсуждения, требования или сторонние проекты.
- Документация описывает текущее поведение, настройку и реальные ограничения реализации.
- Использовать Tailwind для компонентов; глобальный CSS оставлять для токенов, шрифтов и общих utilities.

## Проверки

- Перед передачей задачи выполнять `pnpm lint`, `pnpm format:check`, `pnpm test:run`, `pnpm build` и `git diff --check`.
- Изменения бизнес-логики покрывать тестами поведения, в том числе отмены, повторного запуска и запоздалых ответов.
- Сгенерированные файлы `src/shared/api/generated` не редактировать вручную.
